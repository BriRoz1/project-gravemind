Run your own serverMonta tu servidor

Windows 10 or 11. With MCC installed on that PC the server hosts the matches itself; without it, it still works and the first player hosts.Windows 10 u 11. Si ese PC tiene MCC, el servidor aloja las partidas él mismo; si no, también funciona y las aloja el primer jugador.

Linux: we're working on bringing the dedicated servers to Linux.Linux: estamos trabajando para llevar los servidores dedicados a Linux.

  1. Unzip Project Gravemind into a folder, for example C:\H2Server.Descomprime Project Gravemind en una carpeta, por ejemplo C:\H2Server.
  2. Open a terminal in that folder and run it once. It creates dedicated.toml and playlists\ejemplo.json and closes by itself:Abre una terminal en esa carpeta y ejecútalo una vez. Crea dedicated.toml y playlists\ejemplo.json y se cierra solo: 
    h2gravemind.exe --servers
  3. Edit dedicated.toml: one [[server]] per server, each with its own port.Edita dedicated.toml: un [[server]] por servidor, cada uno con su puerto. 
    master = "master01.gravemind.haloarchive.com:11770, master02.gravemind.haloarchive.com:11770"
admins = ["your player_id"]        # Documents\My Games\Project Gravemind\h2gravemind.ini

[defaults]
max_players = 16
min_players = 2
password = ""                      # empty = open
engine = "server"                  # "player" if this PC has no MCC: the first player hosts

[[server]]
name = "My Slayer"
port = 11780
map = "lockout"
game = "slayer"

[[server]]
name = "My Playlist"
port = 11781
playlist = "ejemplo"               # playlists\ejemplo.json: players vote between 3 games
  4. On your router, forward each server's port as UDP to this PC (11780, 11781...). Let Windows Firewall allow it the first time.En tu router, abre el puerto de cada servidor como UDP hacia este PC (11780, 11781...). Deja que el Firewall de Windows lo permita la primera vez.
  5. Run it again. Each server gets its own window, restarts by itself if it stops and logs to data\<name>\server.log. In a minute they show in everyone's FIND GAMES.Ejecútalo otra vez. Cada servidor tiene su ventana, se reinicia solo si se cae y guarda su registro en data\<nombre>\server.log. En un minuto salen en BUSCAR PARTIDAS de todos. 
    h2gravemind.exe --servers
  6. As an admin you get a box in the server's lobby for commands: kick #2, ban "Name" 1d, map lockout.Como administrador tienes un cuadro en la sala del servidor para comandos: kick #2, ban "Nombre" 1d, map lockout.

Hosting a custom game instead? Only the host opens UDP 11774; or play over Radmin VPN, ZeroTier or Tailscale.¿Solo una partida personalizada? Solo el anfitrión abre el puerto UDP 11774; o jugad por Radmin VPN, ZeroTier o Tailscale.
