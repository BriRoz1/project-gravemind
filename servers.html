HostingAlojar partidas

A custom gameUna partida personalizada

Only the host forwards UDP port 11774 on the router; players who join open nothing. Can't forward ports? Play over Radmin VPN, ZeroTier or Tailscale.Solo el host abre el puerto UDP 11774 en su router; los que se unen no abren nada. ¿No puedes abrir puertos? Jugad con Radmin VPN, ZeroTier o Tailscale.

A dedicated serverUn servidor dedicado

On a Windows PC with MCC the server runs the matches itself (nobody freezes when someone leaves); without MCC the first player's PC runs them. One UDP port per server.En un PC con Windows y MCC el servidor corre las partidas él mismo (nadie se congela cuando alguien sale); sin MCC las corre el PC del primer jugador. Un puerto UDP por servidor.

h2gravemind.exe --servers          # creates dedicated.toml the first time

[[server]]
name = "BR & Sniper"
port = 11780
playlist = "br_sniper"              # players vote between 3 games
engine = "server"                   # this PC runs the matches (needs MCC)

Master servers (UDP 11770) can be run by anyone: Cualquiera puede montar un servidor maestro (UDP 11770): h2gravemind-master (Linux / Docker).
