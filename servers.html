HostAloja

Run your own serverMonta tu propio servidor

You need Windows 10 or 11. If that PC has MCC installed, the server hosts the matches itself; without it, the server still works and the first player to join hosts.Necesitas Windows 10 u 11. Si ese PC tiene MCC instalado, el servidor aloja las partidas él mismo; si no, también funciona y aloja el primer jugador que entra.

  1. Unzip Project Gravemind into a folder, for example C:\H2Server.Descomprime Project Gravemind en una carpeta, por ejemplo C:\H2Server.
  2. Open a terminal in that folder and run it once. It creates dedicated.toml and playlists\ejemplo.json, then closes:Abre una terminal en esa carpeta y ejecútalo una vez. Crea dedicated.toml y playlists\ejemplo.json y se cierra: 
    h2gravemind.exe --servers
  3. Edit dedicated.toml: one [[server]] block per server, each on its own port.Edita dedicated.toml: un bloque [[server]] por servidor, cada uno en su puerto. 
    master = "master01.gravemind.haloarchive.com:11770, master02.gravemind.haloarchive.com:11770"
admins = ["your player_id"]        # Documents\My Games\Project Gravemind\h2gravemind.ini

[defaults]
max_players = 16
min_players = 2
password = ""                      # empty = open
engine = "server"                  # "player" if this PC has no MCC: the first player hosts

[[server]]
name = "My Slayer"
port = 11780
map = "lockout"
game = "slayer"

[[server]]
name = "My Playlist"
port = 11781
playlist = "ejemplo"               # playlists\ejemplo.json: players vote between 3 games
  4. On your router, forward each server's port as UDP to this PC (11780, 11781 and so on), and allow it in Windows Firewall when asked.En tu router, redirige el puerto de cada servidor como UDP hacia este PC (11780, 11781, etc.) y permítelo en el Firewall de Windows cuando lo pida.
  5. Run it again. Each server gets its own window, restarts if it stops and writes its log to data\<name>\server.log. Within a minute it appears in everyone's FIND GAMES.Ejecútalo otra vez. Cada servidor abre su ventana, se reinicia si se detiene y guarda su registro en data\<nombre>\server.log. En menos de un minuto aparece en BUSCAR PARTIDAS para todos. 
    h2gravemind.exe --servers
  6. As an admin, you get a command box in the server's lobby: kick #2, ban "Name" 1d, map lockout.Como administrador tienes un cuadro de comandos en la sala del servidor: kick #2, ban "Nombre" 1d, map lockout.
Just a custom game? Only the host needs to open UDP 11774. Or play over Radmin VPN, ZeroTier or Tailscale with no ports at all. Dedicated servers on Linux are in the works.¿Solo una partida personalizada? Únicamente el anfitrión tiene que abrir el puerto UDP 11774. O jugad por Radmin VPN, ZeroTier o Tailscale sin abrir nada. Los servidores dedicados en Linux están en desarrollo.
